# quarksCharm design system

Authored in Claude Design as a dedicated Design System artifact:
https://claude.ai/artifact/YYCaptqYaAWYgYt2iD6fVu

- Brand book: the artifact's Overview (README).
- Reference screen: component `YearPlanner` (group "Screens") in the same
  artifact: year grid with two painted ranges and one half day, the review
  panel with one previewed run, the header with counters and token expiry,
  the who-is-off column.
- Export: `tokens.json` is the source of truth; `tokens.css` is generated by
  the page. Both are committed here and checked by `bun run ds:check`.
